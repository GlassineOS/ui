settings.appearance.ui-size

Interface size: the same screen at two sizes

Appearance → Size and text → Interface size (shell spec 012). A design pixel is 0.224 mm at Default and 80 % of that at Smaller, on every display; each display’s pixels per millimetre (reported, or measured on its Screen size page, spec 011) turn it into the display’s own pixels. Both frames are the same panel below the top bar, drawn to the same scale: at Smaller the window has more design pixels, so the page lays out again and shows more, rather than shrinking. Row text and buttons keep their minimums (2.8 mm, 7 mm).
