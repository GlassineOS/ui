settings.accounts.browser

Add an account: the server’s own sign-in

Nextcloud signs in on its own page in the system browser; Settings never shows it. Settings shows one still page while it waits, with Show link and Cancel, and goes on by itself when the server grants access. Show link turns the page, in its place, into the link as text and a code to scan with a phone. After 20 minutes without an answer it says so, with Try again. Without a browser on the system, the link and code are the page.
