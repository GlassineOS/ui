What the UI needs from hubd, per node

One list of nodes, each a session, and the entries of its owner’s workflow; the UI builds the tree from owner and entry alone. Marked hubd where hubd already holds it (and where), new where it doesn’t yet. Every field is live: a change is one event with the node’s id and the fields that changed, never a reload of the tree.
