# Link

Links, highlighted marks and inline code inside running text.

- **Consumer provides:** plain markdown links, `==mark==` or search-hit `<mark>`, and backtick code.
- **Links:** text in `pen`. White adds a low `highlight` band beneath (60% down); Editorial uses a 1.5px `pen` underline; Stationery a 1px `gold` underline under blue-black ink. On hover every voice thickens the underline to 2px; nothing animates.
- **Marks:** White and Stationery put `highlight` behind `ink` text; Editorial underlines in `accent` instead of filling.
- **Inline code:** `code` style at 0.8em on `sheet`, radius by voice.
- Don't: colour link text with `highlight`, or rely on colour alone. The band or underline is always there.
