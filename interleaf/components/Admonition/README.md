# Admonition

Material admonitions (`!!! warning "Title"`) restyled per voice; the type is carried by the shape, so it survives the E-ink scheme.

- **Consumer provides:** the admonition type, a title and the body. Every warning or danger names its way out.
- **Shape by type:** note = soft `rule` outline on `sheet`; warning = 2px `ink` outline; danger = the heaviest outline in `pen` (Editorial: 3px double; Stationery: a 3px `wax` ring); tip = dashed.
- **White:** the label is a `highlight` sticker overlapping the top edge, tilted −2°, in Plex Mono caps; `keycap` beneath.
- **Editorial:** a `passe-partout` double frame; the label is a small-caps line in `accent` above a hairline.
- **Stationery:** a `card-stack` card on `paper`; the label in `gold` small caps with a 26px flat `wax` dot for warning and danger; the title in italic.
- Don't: use an icon or colour as the only difference between types.
