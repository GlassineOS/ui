settings.accounts.address

Add an account: the address

Nextcloud asks only for the server’s address, with an example in the empty field; the password is typed on the server’s own page later. Other server asks for the address (a domain, a host, a full address or name@example.org), the user name and the password, with Show password and the line about app passwords. Continue is greyed until the needed fields hold something. Errors stand under the field they are about, in the account service’s words; a refused password never says which field was wrong. With the keyboard open (the system keyboard, purpose url, or private for the password: no suggestions, no learning, no pen) the focused field and Continue stay above the keys, on a page of their own when the rest doesn’t fit.
