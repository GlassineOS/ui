# Table

Markdown tables, booktabs style: rules, never zebra stripes.

- **Consumer provides:** a pipe table. Wide tables scroll inside `.il-table-wrap`.
- **Head:** labels in the voice's label style, coloured `pen` (Stationery: `gold`).
- **White:** 1.5px `ink` under the head and at the foot, dotted `ink` between rows.
- **Editorial:** hairline rules top and bottom of the head, `rule` between rows, a 3px double rule at the foot.
- **Stationery:** a ledger: hairline `gold` above the head, a double `gold` rule beneath, `rule` between rows.
- Mark the cell that matters with `il-mark`, not with colour.
