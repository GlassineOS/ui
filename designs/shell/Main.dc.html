GlassineOS shell, current spec

Every screen runs in 3 voices, always on e-ink. Each board is drawn once in the e-ink greys and carries a voice bar: White, Editorial, Stationery. There are no colour schemes or pens. Settings and Packages boards also switch window size and orientation; the Fit page shows every size side by side. Build and check against all of them.
One board per state, with a stable ID. The ID is the board’s file name. Use it in code, commits and issues. The rules behind the boards (glossary, change flow, origins, contract, acceptance) are in the GlassineOS shell spec doc.
