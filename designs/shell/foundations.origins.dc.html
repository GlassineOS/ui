foundations.origins

Where apps come from

Settings › Apps is the one list of everything installed. Every row carries exactly one origin badge, drawn as an outlined pill with an icon and a word, never colour alone. The origin decides where the app updates and what Remove does. Remove always goes through the change flow. A System package you updated past the system also says “Newer than the system”.

BadgeWhat it isUpdatesRemove
lockCore Runs the tablet: Settings, Software, Files, Terminal.With the systemCan’t be removed. Remove is shown, greyed, with the reason.
inventory_2System Comes with GlassineOS as an Alpine package in the system set.With the systemPlan sheet warns it is part of the system. It moves to Packages › Your changes › Removed by you, where Restore brings it back.
package_2Package Added by you from Packages or a software pack (apk).Packages › UpdatesPlan sheet lists what goes with it. Kept through system updates until you remove it.
storefrontFlatpak From Software (Flathub).In SoftwarePlan sheet; documents stay, shared runtimes stay until unused.
androidAndroid Inside Android apps (Waydroid).In AndroidPlan sheet warns that its data inside Android is deleted.

Software packs are not an origin: a pack installs Packages and Flatpaks, and the app page names the pack it came with. See settings.apps, settings.app.source, settings.app.remove-system.
