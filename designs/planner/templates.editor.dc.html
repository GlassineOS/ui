templates.editor

The template editor

The template with this day’s real entries; the editor only arranges, it never changes an entry. A tap selects a widget (heavy edge). Its tag moves it before or after its neighbour (‹ ›), changes its weight (− +) and holds its settings (⋯: hours, period, slot, turned); dragging the widget onto another’s edge or dragging its own edge does the same by hand. Add widget puts one after the selected; Remove takes the selected out, and entries only it showed stay stored and are named in the (i). Too small: Save is off while a widget would get less than its minimum, in either orientation, and it says by how much. Save applies the template wherever it is used, in one refresh; Cancel after a change asks before it drops the changes.
