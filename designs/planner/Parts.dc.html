The fluid grid: should it live in libglassine-ui?

Recommendation: yes, as a small layout module without drawing, but only once a second program uses it. Home’s widget page (arranging widgets, swapping on shared edges) and Settings’ cards need the same model the planner needs, and one solver keeps them from drifting. Until Home adopts it, the planner keeps its own copy and the interface settles there; moving it later is a version of the library’s contracts, so it should move once, finished. Not implemented here.
