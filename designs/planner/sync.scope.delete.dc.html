sync.scope.delete

Deleting one occurrence: the delete card asks which

A stroke through the typed title of this Thursday’s “team call” opens the delete card as for any event, “Delete this event?”, now with the scope as the delete buttons: This event, This and following events, All events, and Keep. This event frees only this Thursday; the next Thursday still shows the call. Keep, or a tap outside, closes the card and the stroke goes. On the first occurrence the card offers This event and All events only.
