Visual rules (Interleaf White)

  • Ink #111111 on paper; 1.5 px keylines; keycap shadow 0 3px 0 #b4b4b4 on things you press.
  • Pen blue #2747b8 = the one primary action per area, and anything the Steward says (Kalam hand).
  • Highlighter yellow #ffd86b means one thing: waiting for you — the Needs you count, WAITS on sessions, blocking prompts. Search matches use grey, open questions pen blue, toolbars white.
  • Buttons: blue starts an agent; the black split button with the commit symbol is something you do yourself on GitHub, with the most relevant action inline and the rest behind the arrow.
  • Type: section headings are sentence-case sans; monospace is for refs, paths, code and commands only. Help text stays out of the screens unless it prevents a mistake.
  • No side columns that fall below the content: secondary panels (Details on an item, Research & indexes, Keep notes useful) are flyouts; the Sessions list can narrow to icons.
  • Surfaces: screens sit on the grey sheet #f2f2f2 and cards are white paper on it. Ink outlines are for things you can act on; containers use a light rule. The pressed-key shadow marks the one primary action in an area; row actions stay quiet until you hover the row.
  • Severity and failure by outline, never colour alone: double = HIGH / failed, heavy = MEDIUM / blocked, solid = LOW, dashed = INFO / running / draft.
  • Trust in Notes is a word first, then an outline: CURRENT solid ink · OPEN QUESTION yellow · HISTORY grey · RETRACTED double outline and “don’t rely on this” · ARCHIVE · UNREVIEWED dashed, italic · NO STATUS orange and heavy, so it never passes as a fact.
  • Phone (≤ 760 px): the header folds into New + Menu, the Steward becomes a floating button and a full-screen sheet, side columns stack under the content, gutters are 16 px. The rules live in Header’s and Steward’s helmet styles, so every screen inherits them.
  • Personas: an icon on a family tint — build blue #d6e2ff, review violet #eadcff, investigate orange #ffd9b8, write green #d4efdc, organise grey #e2e2e2; the Steward keeps its pen-blue hand-drawn S. The icon tells personas within a family apart, and the persona’s name is always there in text, so colour is never the only cue. A session’s header takes its family tint.
  • Sessions on the same item point at each other: “Also on these items” in the session header, “⇄ also on …” in the Sessions list, persona tabs on the item page. One click switches between, say, the implementer and the reviewer.
  • Terminals are night paper #121212: tool calls pen-blue, your messages on paper chips, questions on yellow.
