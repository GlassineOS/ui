templates.new

A new template, or a copy

From the picker. New opens the editor on an empty template of the kind, named “New day template”; Copy opens it on a copy of the template ringed in the picker, named after it with “, copy”. A tap on the name turns it into a field written with the pen, read as it is written; until a reading arrives the template keeps the name it has. Nothing uses the template until it is saved: Save returns to the picker with it ringed and used by no period yet, where the scope gives it to this day, a range or the default. Edit opens the editor on the template itself, asking first when periods use it.
