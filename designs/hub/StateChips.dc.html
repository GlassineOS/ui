Workflow state · one chip wherever a session shows

The state chip

The session’s workflow state, beside its run state (waiting, running, done). The edge says what kind of state it is and the words say which; the fill never says it alone.

Where it shows

  • Sessions: each row of the list, short, after the run state; the session’s head, short; and a Workflow row under the head with the long chip and “Show the workflow”, which opens the machine panel in place.
  • The work item: each session tab and the embedded session’s head.
  • The Steward panel: the Steward’s own state beside “always on”.
  • Anywhere a session is named (SessionChip: Overview, Work, Roadmap, Knowledge): short, inside the pill.
  • One-state workflows (each action as it is today) show the action’s name. A plain shell has no workflow and shows no chip.
